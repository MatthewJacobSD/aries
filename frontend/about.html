About the project

ARIES

The operating workspace for modern creator agencies. Built to connect creators, campaigns, tasks, clients, and revenue so your team can see what is happening and act on what comes next.

Purpose · Vision · Stack

Why Aries exists

Creator agencies deserve better tools.

Most creator agencies run on a patchwork of spreadsheets, chat messages, and memory. Important context lives in private inboxes. Financial records need reconstruction. New team members spend weeks learning what one person already knows. Aries gives the agency a single operational layer where the work, the people, and the money stay connected.

Problem

Fragmented operations

Campaigns live in one tool. Tasks live in another. Revenue lives in a spreadsheet. The relationships between them exist only in someone's head.

Solution

Connected workspace

Aries keeps creators, campaigns, tasks, clients, and revenue in one place. When something changes in one area, the related records stay aware.

The vision

From onboarding to payout, the work stays connected.

Aries is not another tool your team has to remember to update. The platform is built around the relationships between the work your agency already does. Every record knows what it belongs to, who owns it, and what still needs attention.

Creators

Know who you work with

Keep creator profiles, active work, campaign history, tasks, and relevant financial records connected to the relationship they belong to.

Campaigns

Know what is being delivered

Turn briefs into structured work with deliverables, owners, deadlines, approvals, and campaign activity kept together.

Revenue

Follow the money

Connect revenue, fees, adjustments, shares, and payouts to the creator or campaign they came from so financial activity can be reviewed instead of reconstructed.

Technology

Built with modern, proven tools.

Aries uses a carefully chosen stack that balances developer experience, performance, and reliability. Every technology serves a purpose.

Frontend

HTML, CSS, JavaScript

A clean, accessible interface built with semantic HTML, a custom CSS design system, and vanilla JavaScript. No framework overhead — just fast, maintainable code.

Backend

Python, FastAPI

An async Python backend using FastAPI for high-performance API endpoints, WebSocket connections, and background task processing.

Data

PostgreSQL, Redis

PostgreSQL for reliable, relational data storage. Redis for real-time state, caching, and job queues. Battle-tested, scalable, and well-understood.

Auth

JWT Authentication

Stateless token-based authentication that works across the dashboard, API, and mobile agents. Role-based access control for different workspace members.

Payments

Stripe Integration

Creator payouts, invoice generation, and financial reconciliation through Stripe's proven payment infrastructure.

Infrastructure

Docker, Containerization

Consistent development environments with Docker Compose. One command to start the full stack — database, cache, and API server.

What is next

The roadmap ahead.

Aries is actively evolving. Here is what is planned for the platform.

Phone Farm

Device management

Remotely control and monitor multiple devices from a central dashboard. Manage content distribution across platforms at scale.

Automation

Content automation

AI-powered content scheduling and distribution. Automate repetitive tasks while keeping human oversight on creative decisions.

Integrations

Platform connectors

Direct integration with Fanvue, Telegram, and other creator platforms. Real-time revenue sync and campaign management.

Real-time

Live collaboration

WebSocket-powered live updates across the dashboard. See changes as they happen without refreshing the page.

Built by

A small team with big ambitions.

Aries is built by a team that understands the creator economy from the inside. We have seen how agencies struggle with disconnected tools, and we are building the solution we wish existed.
